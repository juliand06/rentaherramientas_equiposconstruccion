Registro de Devolución & Reporte de Daños

Implementación del ciclo final de vida del alquiler. El proveedor inspecciona la maquinaria retornada, marca el estado de la devolución (DEVUELTO_OK o DEVUELTO_CON_DAÑOS) y opcionalmente registra el informe técnico de daños con el costo estimado de reparación en la base de datos PostgreSQL.

Endpoint: POST /api/reservas/{id}/registrar-devolucion
Entidad Nueva: ReporteDano (descripcion, costoReparacion, fechaReporte)
Entidad Reserva: estadoDevolucion (PENDIENTE, OK, DAÑOS)
Seguridad: hasAnyRole('PROVIDER', 'ADMIN')
Documentación: Swagger OpenAPI ↗
🔐
Acceso de Proveedor Requerido por Spring Security

Sesión actual: Iniciando.... El endpoint requiere rol PROVIDER o ADMIN.

Inspección Técnica de Recepción

✓ DEVUELTO_OK
Sin novedades. La herramienta opera correctamente y no presenta daños.
⚠ DEVUELTO_CON_DAÑOS
Presenta rotura, avería o pérdida de piezas. Requiere reporte de reparación.
